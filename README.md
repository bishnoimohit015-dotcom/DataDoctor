# DataDoctor

A beginner-friendly CSV data quality analysis tool built with Python, Pandas, and Streamlit.

## Features

DataDoctor currently provides:

- CSV file upload
- Number of rows and columns
- Column names and detected data types
- Missing-value counts for each column
- Duplicate-row count
- Basic statistics for numerical columns
- Preview of uploaded data

## Tech Stack

- Python
- Pandas
- Streamlit
- Git/GitHub
